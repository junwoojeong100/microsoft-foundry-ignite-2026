# 실습 환경 규칙

이 문서는 실습 연습용으로 만든 가상의 규칙입니다. 실제 워크샵의 배정값은 운영자의 안내를 따릅니다.

## 리소스

- 참가자 한 명이 리소스 그룹 하나를 씁니다. 이름은 rg-user 뒤에 두 자리 번호를 붙입니다(예: rg-user07).
- 지역은 North Central US만 사용합니다.
- 모델은 gpt-6.1-terra 하나만 배포하며 배포당 한도는 분당 10,000 토큰(10,000 TPM)입니다.

## 정리와 보안

- 행사가 끝나면 오후 3시까지 운영자 안내에 따라 리소스를 정리합니다.
- 고객 데이터와 개인 정보는 실습에 입력하지 않습니다.
- 비밀번호와 API 키는 화면 공유나 채팅에 붙여 넣지 않습니다.
